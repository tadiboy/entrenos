# Entrenos

App de entrenamientos (PWA) para el celular: rutinas full body con kettlebell y calistenia, temporizador de descanso, registro de reps y peso, historial y racha semanal.

- Abrir: https://tadiboy.github.io/entrenos/
- iPhone: abrir el link en Safari → Compartir → "Agregar a inicio".
- Funciona sin conexión; los datos se guardan solo en el dispositivo (exportar/importar JSON desde Ajustes).
- Sin backend ni datos personales en este repo.
